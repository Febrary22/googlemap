# 내 타임라인 영상 만들기

구글 타임라인(Google Timeline) 데이터를 업로드해서 나만의 이동 경로 영상을 **브라우저 안에서** 만들고, 링크 하나로 주변 사람들과 공유할 수 있는 웹앱입니다. 서버가 없습니다 — 업로드한 위치 데이터는 절대 어디로도 전송되지 않고, 이 페이지를 여는 사람의 브라우저 메모리 안에서만 처리됩니다.

## 사용 흐름 (4단계)

1. **타임라인 받기** — 안드로이드 / 아이폰 / PC(Google Takeout, 10년치 전체 기록용) 각각의 내보내기 방법 안내.
2. **업로드 & 기간 선택** — JSON 파일(여러 개 동시 업로드 가능)을 올리고, 전체 기간/올해/작년/최근 5년 프리셋이나 연·월 체크박스, 또는 `2025-01-01 ~ 2025-12-31` 같은 정확한 날짜로 범위를 지정.
3. **영상 설정** — 지도 스타일(라이트/다크/컬러/위성/미니멀), 경로선 색상·두께·스타일(실선/점선/네온), 궤적 유지 방식(전체 유지 vs. 혜성 꼬리 효과), 카메라 모드(고정/점점 확장/따라가기), 오래 머문 장소 자동 추천 + 지도 클릭으로 원하는 지점 확대, 음악 업로드(볼륨/시작지점/페이드아웃), 영상 길이, 화면 오버레이(날짜/누적 거리/진행바/요약 카드), 화면 비율(16:9/9:16/1:1)·해상도·프레임레이트. 오른쪽에 실시간 미리보기가 있습니다.
4. **영상 만들기** — 설정대로 실제 녹화(브라우저 `MediaRecorder` 사용) 후 바로 다운로드.

## 지원하는 타임라인 파일 형식

파서가 아래 형식을 자동으로 인식하고 섞어서 올려도 병합합니다.

- **온디바이스 내보내기(`Timeline.json`, 2024년 12월 이후)**: `semanticSegments`(`visit`/`activity`/`timelinePath`) + `rawSignals`
- **Google Takeout — Semantic Location History**: `timelineObjects`(`placeVisit`/`activitySegment`), 월별 파일 여러 개를 한 번에 선택 가능
- **Google Takeout — `Records.json`**: 원본 GPS 핑 전체 (`locations[]`, E7 좌표)

좌표는 `geo:lat,lng`, `"37.5°, 127.0°"`, `{latitude,longitude}`, `{latitudeE7,longitudeE7}` 등 어떤 형태로 와도 처리하도록 만들었습니다.

## 기본 기능 + 추가로 넣은 기능

요청하신 기능(다운로드 안내 → 업로드/기간 선택 → 음악/선 모양/확대 지점 등 영상 설정) 외에, 기존 타임라인 비주얼라이저들을 참고해서 아래를 더했습니다.

- **이동하는 곳 자동 확대 (기본 카메라 모드)** — 전체 경로를 한 화면에 고정하는 대신, 현재 시점 기준 앞뒤 몇 시간의 이동만 모아 그 범위에 맞춰 확대해요. 평일엔 집·회사 반경으로 확대되어 출퇴근이 크고 선명하게 보이고, 주말에 멀리 이동하면 카메라가 그 지역으로 자연스럽게 스윽 이동합니다("확대 범위" 슬라이더로 민감도 조절 가능)
- **이동수단별 경로 색상** (도보/자동차/자전거/비행 등을 자동 감지해서 다르게 표시)
- **장거리 이동(비행) 자동 감지 + 점선 아치 표시** — 데이터 공백을 이상한 직선으로 잇지 않음
- **오래 머문 장소 자동 추천** — 체류 시간 기준 상위 장소를 골라서 체크만 하면 확대 연출
- **혜성 꼬리 효과** — 지금까지의 전체 경로 대신 최근 궤적만 남기고 서서히 사라지는 스타일
- **오래 머문 곳에서 살짝 더 머무르는 페이싱** — 기계적으로 균등한 속도 대신 자연스러운 완급 조절
- **화면 비율 3종(16:9/9:16/1:1)** — 유튜브뿐 아니라 릴스·쇼츠용 세로 영상도 바로 제작
- **누적 이동거리 · 날짜 · 진행바 오버레이**, **마지막 요약 카드**(총 이동거리, 방문 장소 수, 가장 오래 머문 곳 Top 3)
- 브라우저가 지원하면 **MP4로 바로 녹화**(사파리 등), 아니면 널리 재생되는 **WebM**으로 자동 대체

## 개인정보 & 지도 데이터 출처

- 업로드한 JSON은 이 브라우저 탭 메모리에만 존재하며 새로고침/탭 종료 시 사라집니다. 서버로 전송되는 유일한 네트워크 요청은 지도 타일 이미지(배경 지도)뿐입니다.
- 지도 타일: © [OpenStreetMap](https://www.openstreetmap.org/copyright) contributors, © [CARTO](https://carto.com/attributions) / 위성 이미지 © Esri.

## 로컬에서 실행하기

빌드 과정이 없는 순수 정적 사이트입니다. 아무 정적 서버로 루트 폴더를 띄우면 됩니다.

```bash
npx serve .
# 또는
python3 -m http.server 8000
```

## GitHub Pages로 배포해서 링크 공유하기

`.github/workflows/deploy.yml`이 포함되어 있습니다. 저장소 **Settings → Pages → Build and deployment → Source**를 **GitHub Actions**로 한 번 설정해두면, `main`(또는 `master`) 브랜치에 푸시할 때마다 자동으로 배포되고 `https://<사용자명>.github.io/<저장소명>/` 링크가 생깁니다. 이 링크를 주변 사람들에게 공유하면 각자 자신의 타임라인 파일로 영상을 만들 수 있습니다.

## 폴더 구조

```
index.html            4단계 UI
css/styles.css         전체 스타일
js/geo.js              지도 투영/거리 계산 (Web Mercator)
js/parser.js           타임라인 JSON 파서 (여러 포맷 자동 인식)
js/mapCanvas.js         캔버스 기반 타일 지도 렌더러 (녹화 가능하도록 DOM 지도 대신 직접 구현)
js/timeline.js          기간 필터링 + 카메라 경로/확대 연출 스케줄 생성
js/sceneRenderer.js     한 프레임(배경+경로+마커+오버레이) 그리기
js/videoRecorder.js     캔버스+오디오를 MediaRecorder로 실시간 녹화
js/pickerMap.js         확대 지점을 고를 때만 쓰는 작은 Leaflet 지도
js/app.js               전체 UI 상태 관리 및 이벤트 연결
```

## 알려진 제한사항

- 매우 큰 파일(수십만 개 지점)은 파싱/디코딩에 몇 초 정도 걸릴 수 있습니다.
- 위성 지도(Esri)나 컬러/다크/라이트(CARTO) 배경은 CORS가 허용된 타일 서버만 사용해서 녹화가 항상 정상 동작하도록 했습니다. 배경 지도가 필요 없다면 "없음(미니멀 배경)" 옵션이 가장 가볍고 빠릅니다.
- 녹화는 실시간으로 진행됩니다(영상 길이만큼 실제로 시간이 걸려요). 진행률 표시줄로 확인할 수 있습니다. 다른 프로그램이 CPU를 많이 쓰고 있는 상태라면 마지막 장면이 설정한 길이보다 살짝(1~2초) 더 길어질 수 있어요 — 녹화 중에는 다른 무거운 작업을 같이 켜두지 않는 걸 추천해요.
